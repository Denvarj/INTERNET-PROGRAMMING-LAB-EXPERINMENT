# StayEase — Hotel Room Booking Website

A responsive front-end project based on Question 2 of the Internet Programming Lab Experiments document: an online hotel room booking website.

## Features included
- Search hotel listings by hotel name, city, or category.
- Filter listings by Luxury, Business, and Budget.
- Hotel cards with room category, city, rating, price, and description.
- Booking form with guest details, dates, guest count, and estimated total.
- Demo booking history with reference number and cancel option.
- Admin demo panel to add hotel listings.
- Responsive layout for desktop, tablet, and mobile.
- Uses browser localStorage to retain demo listings and bookings.

## Run the project
1. Extract `Hotel_Room_Booking_Website.zip`.
2. Open the `Hotel_Room_Booking_Website` folder.
3. Double-click `index.html` to open it in a modern browser.
4. Search for a city such as Chennai, Pondicherry, Coimbatore, or Ooty.
5. Click **View & book**, fill the form, and confirm a demo booking.
6. Scroll to **Admin panel** to add a hotel listing.

## Files
- `index.html` — page structure
- `style.css` — styling and responsive layout
- `script.js` — search, filters, demo booking, booking history, and admin listing logic

## Important limitation
This is a front-end educational demo. It does not connect to a server or database, send confirmation emails, process real payments, provide secure authentication, or verify live room availability. For a production system, add a backend, database, authentication, payment gateway, and email service.
