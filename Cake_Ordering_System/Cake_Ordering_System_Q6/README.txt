SWEETCRUMBS — ONLINE CAKE ORDERING SYSTEM (QUESTION 6)

Project type:
Front-end website made using HTML, CSS, and JavaScript.

How to run:
1. Extract Cake_Ordering_System_Q6.zip.
2. Open the Cake_Ordering_System_Q6 folder.
3. Double-click index.html.
4. The website opens in Chrome, Edge, or another browser.

Features included:
- Browse cake collection with names, flavors, categories, and prices.
- Search cakes and filter by occasion/category.
- Customize cake size and quantity.
- Add a message to the cake.
- Enter customer name, phone, delivery address, and delivery date.
- Choose a demo payment option.
- Calculate the estimated order total.
- Generate a demo order reference and display recent orders.
- Responsive layout for desktop and mobile screens.

Important:
This is a front-end academic demo. It does not connect to a real bakery, payment gateway, email service, or delivery system. Order history is stored in the browser's local storage on that device.
