SKYBOOK - FLIGHT RESERVATION SYSTEM
Internet Programming Lab - Question 5

Included:
- index.html: website layout and forms
- style.css: responsive styling
- script.js: sample flight search, booking reference generation, ticket lookup, cancellation and admin overview

How to run:
1. Extract this ZIP file.
2. Open the Flight_Reservation_System folder.
3. Double-click index.html, or open it with Google Chrome.
4. Try sample routes: Chennai to Delhi, Chennai to Mumbai, Delhi to Bengaluru, Bengaluru to Chennai.
5. Select a flight and complete the passenger form.
6. Save the generated booking reference to view or cancel the ticket.

Important:
This is a front-end lab demo using sample flight information. It does not connect to real airline systems, a backend database, or a real payment gateway. Bookings are stored only while the page remains open and will clear when refreshed.
