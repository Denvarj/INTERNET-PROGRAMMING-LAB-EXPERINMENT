# RouteGo — Online Bus Ticket Booking Website

This project is based on Question 3 in the supplied Internet Programming Lab Experiments PDF: an online bus ticket booking system.

## Features
- Search buses by source, destination, and journey date.
- Display departure/arrival times, travel duration, bus type, available seats, ratings, and fare.
- Filter buses by AC Sleeper, AC Seater, and Non-AC.
- Demo seat selection and passenger booking form.
- Ticket history with reference number and cancellation option.
- Admin demo form to add bus routes.
- Responsive layout for desktop and mobile.
- Browser localStorage saves demo routes and tickets.

## Run
1. Extract `Question_3_Bus_Ticket_Booking_Website.zip`.
2. Open the `Bus_Ticket_Booking_Website` folder.
3. Double-click `index.html`.
4. Search a route, choose a bus, and create a demo ticket.
5. Scroll to Admin panel to add a route.

## Files
- `index.html` — structure
- `style.css` — styling and responsive layout
- `script.js` — route search, filtering, booking, ticket history, and admin listing

## Limitations
This is a front-end academic demo. It does not connect to a backend/database, verify real seat availability, process payments, send confirmation emails, or provide secure authentication. These need server-side implementation for a production system.
