RAILRESERVE - TRAIN RESERVATION SYSTEM
Internet Programming Lab - Question 4

Files:
- index.html : website pages and forms
- style.css  : layout and responsive styling
- script.js  : demo train search, booking, PNR status, cancellation and admin overview

How to run:
1. Extract the ZIP file.
2. Open the Train_Reservation_System folder.
3. Double-click index.html, or open it with Google Chrome.
4. Search a route such as Chennai to Bengaluru or Bengaluru to Chennai.
5. Select a train, fill passenger details and confirm the booking.
6. Copy the generated PNR to check status or cancel the ticket.

Note:
This is a front-end academic demonstration. It uses sample train data and temporary in-memory bookings. It does not connect to real railway data, a backend database, or a real payment gateway. Refreshing the page clears demo bookings.
