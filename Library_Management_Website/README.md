# Campus Library — Internet Programming Lab (Question 1)

A responsive front-end demo for the **Local Library Management Website** described in Question 1 of the provided Internet Programming Lab experiments.

## Features
- Book catalog with title/author/category search and category filtering
- Book details dialog and demo borrow action
- Student demo sign-in and borrowing history
- Admin dashboard to add/delete catalog entries
- Contact form with local demo feedback
- Responsive layout for desktop and mobile
- Uses browser `localStorage` for catalog changes and `sessionStorage` for the demo student session

## Run the project
1. Extract the ZIP file.
2. Open the extracted `Library_Management_Website` folder.
3. Double-click `index.html`, or open it in a browser.
4. No installation is required.

## Important
This is a front-end lab demonstration. Login is not secure authentication, data is stored only in the current browser, and the contact form does not send messages to a server. A real deployment would require a backend, database, password security, and server-side authorization.

## Files
- `index.html` — page structure
- `style.css` — styling and responsive layout
- `script.js` — catalog search, demo account, borrowing, and admin interactions
